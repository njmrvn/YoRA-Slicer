# profiles/

Your own data, kept on this PC (not in the repository):

| Folder / file | What |
|---|---|
| `*.json` | print profiles (Prepare → Print settings → Save as…) |
| `robots/` | robot models: load a `.robot` robot model file in the Robot step and it is saved here |
| `tools/` | tool head 3D models (Robot step → Tool → Import model…) |
| `cells/` | robot cells (robot, tool, frames, positions) |
| `materials/` | your materials (Prepare → Material) |
| `posts/` | your post-processors (Export → Edit…) |

The app creates each folder the first time it saves something there.
